Edit fonts, spacing, and colors: open style.css.
Portrait: add an image named portrait.jpg in this folder.

To publish via GitHub Pages:
1. Create a public repository named YOURUSERNAME.github.io.
2. Upload index.html and style.css (and portrait.jpg when ready) to the root of the repository.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Commit future edits to update the public site automatically.
